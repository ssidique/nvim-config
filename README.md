# Neovim Config

Personal Neovim configuration in Lua, using [lazy.nvim](https://github.com/folke/lazy.nvim) as the plugin manager.

## Plugins

- [catppuccin/nvim](https://github.com/catppuccin/nvim) — colorscheme (Mocha flavour)
- [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig) + [mason.nvim](https://github.com/williamboman/mason.nvim) — LSP setup (`pyright`, `lua_ls`)
- [nvim-cmp](https://github.com/hrsh7th/nvim-cmp) — completion
- [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter) + textobjects — syntax highlighting and text objects
- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) — fuzzy finder
- [oil.nvim](https://github.com/stevearc/oil.nvim) — edit the filesystem like a buffer
- [gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim) — git gutter signs, hunks, blame
- [lazygit.nvim](https://github.com/kdheepak/lazygit.nvim) — lazygit TUI integration
- [flash.nvim](https://github.com/folke/flash.nvim) — jump motions
- [nvim-surround](https://github.com/kylechui/nvim-surround) — surrounding pairs
- [nvim-autopairs](https://github.com/windwp/nvim-autopairs) — auto-close brackets
- [snacks.nvim](https://github.com/folke/snacks.nvim) — UI utilities
- [avante.nvim](https://github.com/yetone/avante.nvim) — AI assistant
- [which-key.nvim](https://github.com/folke/which-key.nvim) — keybinding popup
